# 🌟 Clear Presentation Rubric

| Category | Criteria (Meets / Does Not Meet) |
| ----- | ----- |
| **Clarity of Purpose & Message** | ☐ Includes a slide near the beginning that explicitly lists the 2–3 key takeaways of the work, which will guide the entire talk  ☐ Key takeaways are revisited near the conclusion |
| **Audience-Friendly Visuals (Figures & Tables)** | ☐ Includes at least three figures/tables/visualizations  ☐ No more than one figure per slide ☐ All figures used are simplified visuals (none are copy/pasted from the paper) ☐ All figure axes, labels, and symbols are defined on slide ☐ Axes and components of figures/tables are clearly introduced ☐ Each visual has an accompanying clearly explained takeaway sentence/phrase |
| **Slide Titles as Summary** | ☐ Slide titles clearly convey the main point/takeaway of each slide, not just topic (e.g., not “Results”) |
| **Final Slide & Conclusion** | ☐ Final slide reinforces 2–3 key takeaways  |
| **Speaker Time Distribution** | ☐ Speaking time is evenly distributed among speakers |
| **Questions & Understanding** | ☐ Able to answer most audience questions clearly and accurately |
