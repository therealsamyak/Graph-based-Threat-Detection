\subsection{Edge Scoring}
\label{sec:edge_scoring}

Edges are scored with a unified weighted sum over the features selected by the feature audit (Section~\ref{sec:feature_selection}) and weighted by the Nelder-Mead optimizer (Section~\ref{sec:weight_optimization}):

\begin{equation}
s = \sum_{i=1}^{k} w_i^* \cdot f_i
\end{equation}

where $w_i^*$ are the optimized weights and $f_i$ are the selected features. For the combined variant, $f_i \in \{\texttt{is\_ntlm}, \texttt{dst\_in\_degree}, \texttt{is\_network\_logon}, \texttt{dst\_total\_degree}, \texttt{edge\_rarity}\}$. The auth-only variant uses $\{\texttt{src\_in\_degree}, \texttt{is\_ntlm}, \texttt{src\_out\_degree}\}$. The flow-only variant uses $\{\texttt{src\_burst\_score}, \texttt{dst\_inter\_arrival\_mean}, \texttt{dst\_inter\_arrival\_std}\}$. Non-binary features receive a percentile rank transform before scoring to reduce outlier influence; binary features pass through unchanged.

Edges where either endpoint is a user account (contains \texttt{@}) or where source equals destination (self-loop) receive a score of 0.0, since these carry no red-team signal in our labeled data.
