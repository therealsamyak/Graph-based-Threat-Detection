\subsection{Baseline Pipeline Comparison}
\label{sec:baseline_pipeline}

We compare the graph-based detector against two unsupervised tabular baselines: One-Class SVM and Isolation Forest. Both baselines operate on the same cached edge tables produced by the graph pipeline.

\subsubsection{Protocol}

All methods use the same LANL-2015 edge feature tables and the same three variants: combined authentication-plus-flow features, authentication-only features, and flow-only features. Baselines use the same feature whitelists identified by the feature audit (Section~\ref{sec:feature_selection}), ensuring identical feature sets across all methods. Non-binary columns are converted to percentile ranks; binary columns are left unchanged. Edges marked as self-loops or user metadata edges are excluded from evaluation.

Ground truth comes from LANL red-team source-destination pairs. A graph edge is positive when its \texttt{(src, dst)} pair appears in that set. The one-class baselines train only on normal edges, then evaluate on held-out normal edges plus all positive red-team edges. This is the right contract for unsupervised anomaly detection: learn normal behavior first, then score what looks abnormal.

One-Class SVM uses an RBF kernel with \texttt{nu=0.1}. Features are standardized with \texttt{StandardScaler} fitted on the normal training split, and anomaly scores are obtained by negating \texttt{decision\_function()}. Isolation Forest uses 100 trees, \texttt{contamination="auto"}, and seed 42; anomaly scores are obtained by negating \texttt{score\_samples()}.

Thresholds and pair-level metrics use the same optimizer and metric calculator as the graph detector. Baseline score arrays are evaluated through the same threshold sweep and pair-metric computation pipeline, keeping recall, false-positive rate, precision, F1, and AUC aligned across all approaches.

\subsubsection{Interpretation}

The combined variant tells a clear story. The graph-based method has the highest AUC (0.959) and the lowest false positive rate (0.004) of any method. Isolation Forest catches more red-team pairs in absolute terms (181 vs.\ 65), but pays for it with a sevenfold higher FPR (0.029). In a real deployment, that difference in false alarm volume matters more than raw recall. One-Class SVM is the most conservative of the three: it fires on almost nothing (recall 0.052), and its AUC of 0.800 reflects weak ranking ability on combined features.

The authentication-only variant shifts the picture. All three methods detect most red-team pairs (recall above 0.92), because auth events contain strong directional signals like NTLM usage and unusual logon types. The graph method stands out for its FPR: 0.006, compared to 0.029 for Isolation Forest and 0.107 for One-Class SVM. That low false alarm rate, paired with the highest AUC (0.984), means the graph method is both sensitive and precise on auth data. Isolation Forest matches on recall but accepts roughly five times more false positives. One-Class SVM has the worst precision (0.020), meaning most of its alerts are noise.

The flow-only results confirm that network flow records alone are insufficient for lateral movement detection. Every method has near-zero recall and near-zero precision. The graph method still manages an AUC of 0.963, suggesting it can rank edges better than random, but the operating point is so poor that the ranking is not actionable. Without authentication semantics, detection fails.

Taken together, these results support two design choices in the pipeline. First, authentication events are the primary detection signal. Second, the graph structure extracts more from that signal than tabular methods can, because it models relationships between hosts rather than treating each edge as an isolated data point.

\subsubsection{Reproduction}

All experiments can be reproduced by running the baseline comparison module on the cached graph-pipeline outputs. The module accepts a run identifier and optional variant filter. Results and figures are written to a timestamped output directory.
