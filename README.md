# Graph-Based Lateral Movement Detection

**ECE 239AS — UCLA**
Ibrahim Pehlivan, Wesley Gunawan, Samyak Kakatur

Fuses network flow + authentication logs into a unified graph; scores each edge by weighted feature sum (Nelder-Mead tuned for ROC AUC).

## Data

Download LANL-2015 → [`data/README_DATA.md`](data/README_DATA.md). Place in:

```
data/LANL-Dataset-2015/
├── auth.txt.gz
├── flows.txt.gz
└── redteam.txt.gz
```

## Data Processing

```bash
uv sync                  # install deps
uv run feature.py        # feature audit  → feature_results/
uv run main.py           # detection      → results/
uv run baselines.py      # SVM, IF        → baseline_results/
uv run eval.py           # evaluation     → analysis_results/
```

## Figures

Each figure is generated by its own script in `scripts/`. Run one per figure:

```bash
uv run scripts/fig_roc.py          # ROC curves
uv run scripts/fig_ablation.py     # ablation study
uv run scripts/tbl1_methods_comparison.py   # methods table
# ... etc, one uv run per script
```

Optional `--run-id ID` pins to a specific run. Output → `figures/`.

## Config

All configuration options are in `pipeline_config.json`.

### `data`

| Key            | Default                    | Effect                                                                                                |
| -------------- | -------------------------- | ----------------------------------------------------------------------------------------------------- |
| `lanl_dir`     | `"data/LANL-Dataset-2015"` | Path to the dataset (relative to repo root)                                                           |
| `window_size`  | `3600`                     | Seconds (±) around each red-team event; events outside any window are skipped to bound memory         |

### `graph`

| Key              | Default  | Effect                                       |
| ---------------- | -------- | -------------------------------------------- |
| `progress_every` | `500000` | Log progress every N streamed events         |

### `scoring`

| Key                     | Default                        | Effect                                                                                          |
| ----------------------- | ------------------------------ | ----------------------------------------------------------------------------------------------- |
| `threshold_mode`        | `"auto_optimize"`              | `"auto_optimize"` sweeps percentiles to maximize F1; any other value uses `threshold_percentile` |
| `threshold_percentile`  | `99`                           | Percentile used as threshold when **not** in auto_optimize mode                                 |
| `threshold_search_range`| `[90,95,97,99,99.5,99.9]`      | Candidate percentiles swept during auto_optimize                                                |
| `path_boost_factor`     | `0.1`                          | Score boost added to edges that appear in top-scoring paths                                     |
| `temporal_decay_rate`   | `0.0`                          | Exponential decay rate for temporal weighting (`0` = disabled)                                   |
| `max_hops`              | `4`                            | Max path length during path enumeration                                                          |
| `top_k_paths`           | `50`                           | Number of top-scoring paths retained                                                             |
| `top_outgoing_per_node` | `10`                           | Max outgoing edges followed per node during path search                                          |

### `features`

| Key                       | Default | Effect                                                                                      |
| ------------------------- | ------- | ------------------------------------------------------------------------------------------- |
| `betweenness_node_limit`  | `5000`  | Above this node count, switch from exact to approximate betweenness centrality             |
| `approximate_betweenness` | `true`  | Use igraph cutoff-based approximate betweenness                                            |
| `betweenness_cutoff`      | `3`     | Cutoff parameter for approximate betweenness                                               |
| `temporal_burst_window_pct`| `0.1`  | Fraction of a node's active span used for burst-score computation                           |
| `max_workers`             | `20`    | Parallel workers for feature extraction and path scoring                                    |
